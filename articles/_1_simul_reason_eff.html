simul: reasoning efficiency

Let’s try to define a metric which would measure reasoning efficiency. How much can model/effort combination ‘solve’ per token.

To do that, we need to first establish ‘task complexity’ - how complicated is ‘thing’ we try to measure?

Let’s say we don’t know the complexity absolute measure, but we can assume that complexity can be represented as some 2 dimensions.

In our case, we have:

  • for each endgame, how well-separated top candidate is?
  • for N endgames, how ‘additive’ is complexity?

Ideally, it should be additive, or even more efficient than that - as some reasoning about ‘algorithm’ can be shared.

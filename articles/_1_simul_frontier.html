Testing frontier

Setup

Let’s create a dataset of 60 endgames, split it into batches of all divisor sizes and run same model with the same settings. The 60 samples were picked to be more likely to be complex - more valid choices, less prominent top option.

The goal is to test if larger set of ‘same’ tasks is more complex to the models.

Results

At frontier, this seems fairly saturated. gpt-6.1-sol is very close to be perfect and n_tokens actually decreases. We don’t see reasoning traces, but we can assume that some of the thinking is shared on figuring out the algorithm.

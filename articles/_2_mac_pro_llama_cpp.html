running llama.cpp server(s)

Power setup and tests

  1. Manually turn on fans to max:
cd /sys/bus/acpi/devices/APP0001:00/
for n in 1 2 3 4; do   echo 1 | sudo tee fan${n}_manual >/dev/null;   cat fan${n}_max | sudo tee fan${n}_output >/dev/null; done
  1. Manually set clock on all GPUs (level 2-3 is reasonable)
L=2   # or 3                                                             
for c in 0 1 2 3; do                                                     
  D=/sys/class/drm/card$c/device                                         
  echo manual | sudo tee $D/power_dpm_force_performance_level > /dev/null
  echo $L     | sudo tee $D/pp_dpm_sclk > /dev/null                      
  echo "card$c: $(grep '\*' $D/pp_dpm_sclk)"                             
done

Now each server separate on each GPU:

./build-hip/bin/llama-server -m ~/llms/Qwen3.8-27B/Qwen3.8-27B-UD-Q4_K_XL.gguf  --chat-template-kwargs '{"reasoning_effort":"low"}' -a Qwen3.8-27B-UD-Q4_K_XL.gguf --temp 1.0 --top-p 0.95 --top-k 20 --min-p 0.0 --spec-type draft-mtp --spec-draft-n-max 3 --jinja -ngl 99 --reasoning-budget 4096 --reasoning-budget-message $'\n\nOK, I have thought enough. Time to act.' --device ROCm3 --host 0.0.0.0 --port 8083

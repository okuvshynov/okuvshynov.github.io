Specific endgames

Let’s look at specific games to see if we can find any interesting patterns. We are working on endgame version of simul.

First, thing to fix: in some samples, the probability for top choice on the last step is equal for several options. For example, greedy player solved the puzzle on the next turn with these probabilities:

'3045': 0.01076

'4517': 0.13455
'4537': 0.02152
'6537': 0.13455
'7540': 0.13455
'7541': 0.13455
'7542': 0.08073

Multiple options are 0.13455, so in this case, the fact that greedy player solved it in one move is partially luck, and it will be better to filter such cases out. Having dataset where there’s a single most correct answer, yet with different complexity is likely to help us find more interesting patterns.

For the next steps we could compare model answer against entire greedy output vector and compute regret. We can make it linear or logistic, very similar to log loss. Or, ask model to produce multiple candidates/probabilities, not pick a single answer. This might be a good metric, we shall look into that later.

Deepseek is still doing great, but more complicated samples have 1 mistake each and need visibly more tokens. Local Qwen 3.8-27B model shows very clear drop from cases which look easy to cases which look hard.

Carefully constructing the dataset with a mix of easy/medium/hard individual problems and simul session size can allow cheap and efficient evaluation of models up to the current (Oct 2026) frontier. We can also easily have very similar public/hidden datasets and see if there’ll be a drift as models pick next iteration of web data.
